# QuickNotes App

QuickNotes is a lightweight, responsive note-taking web utility built from scratch using pure HTML5, CSS3, and modern JavaScript. It allows users to quickly organize tasks, thoughts, and ideas down into structured categorical columns with localized storage caching retention.

## Features
- Dynamic creation and deletion of custom tracking notes.
- Visual theme labeling for Personal, Work, and Study categories.
- Real-time instant keyword text filtering.
- Client-side persistence utilizing local browser memory.
- Fluid responsive configurations matching small devices.

## How To Run Locally
1. Clone or download this project folder onto your desktop environment.
2. Open the file `index.html` natively inside any modernized web browser.

## What I Learned
1. Implementing scalable client array handling using native `localStorage` parsing methods.
2. Protecting user interfaces from malicious scripts by creating structural interface tags strictly using `createElement` and `textContent`.
3. Creating dynamic responsive page scaling behaviors via customized CSS flex elements coupled with `@media` device break thresholds.
